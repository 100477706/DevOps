# Architecture Decision Records (ADR)

Este directorio contiene las decisiones de arquitectura del proyecto NewsRadar.

## ¿Qué es un ADR?

Un Architecture Decision Record (ADR) documenta una decisión arquitectónica importante tomada por el equipo, junto con su contexto, las opciones consideradas y las consecuencias de la elección.

## Formato de un ADR

Cada ADR sigue la estructura:
- **Título**: Nombre descriptivo de la decisión.
- **Estado**: Propuesto / Aceptado / Obsoleto / Reemplazado.
- **Contexto**: El problema o necesidad que motiva la decisión.
- **Decisión**: La elección tomada.
- **Consecuencias**: Impacto positivo y negativo de la decisión.
